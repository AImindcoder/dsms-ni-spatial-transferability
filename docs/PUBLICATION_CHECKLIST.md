# Scientific publication checklist

- [ ] Confirm all authors approve the repository contents
- [ ] Confirm code copyright and MIT licensing permissions
- [ ] Locate the final five-model benchmark implementation
- [ ] Identify and verify final analysis input data
- [ ] Confirm dataset redistribution permissions
- [ ] Verify final spatial fold assignments
- [ ] Verify archived ExtraTrees experiment provenance
- [ ] Identify final prediction and metric outputs
- [ ] Check scripts for credentials and sensitive information
- [ ] Create tested Python environment requirements
- [ ] Confirm numerical results against the manuscript
- [ ] Document commands to reproduce the published figures
- [ ] Create a versioned GitHub release
- [ ] Archive the release and obtain a DOI
